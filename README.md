# Sports Results — Vibe-Coding Project

> This repository is a vibe-coding experiment — a learning playground, not a production example.

This app started as a personal exploration of building a real-time sports scoreboard UI while collaborating with AI. The goal here was the journey: learning, experimenting, iterating, and seeing how quickly ideas can be prototyped when pairing with AI tools.

Why this repo exists
- To learn: I used this project to practice React, Vite, and integrations with live data sources.
- To experiment: Many components and utilities were written rapidly and iteratively while exploring ideas.
- To share the process: The code documents a development journey — decisions, corrections, and trade-offs are part of that story.

Important notes for visitors
- Not production-ready: This is intentionally informal and experimental. Do not treat the code here as best-practice examples for architecture, security, or performance.
- Rough edges expected: You will find quick hacks, debugging logs, TODOs, and places where I prioritized learning speed over polish.
- Judgment-free zone: If you spot issues, suggestions are welcome — but please remember this repo documents a learning journey.

If you want to run or explore locally
- See `README_DEPLOY.md` for deployment instructions (this repo includes a GitHub Pages setup).
- To run locally in development:

```bash
npm install
npm run dev
```
